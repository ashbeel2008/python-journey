# PYTHON PLAN

**Goal:** by Month 3, build small real tools and earn your first **$50–150**. By Month 6,
**$300–800/month**. Use that to buy better hardware — then restart the video editing plan with a
machine that can actually run it.

**Positioning:** **Python automation + a portfolio of small, real applications** — for creators,
gaming communities, and small businesses.

Two tracks, both required:
- **Portfolio** — software people can open and try. Proof you can build.
- **Service** — small paid work that the portfolio makes easier to sell.

Why this lane:
- It runs perfectly on 6 GB RAM — unlike Premiere.
- A working app is proof *and* a sales demo. Most beginners have neither.
- Small automation work is what beginners actually get paid for first.
- Projects are small enough to finish in a week.

**Time:** 1 hour a day. **20 minutes learning, 40 minutes building.**

---

## The rule that decides this

> **Build more than you watch. 80% code, 20% tutorials.**

You do not "learn Python, then earn." You learn enough to build a small useful thing, sell that
thing, and let the next project teach you more. Watching 200 hours of tutorials produces nothing
you can charge for.

**Mastery is not the first goal.** Competence is. Mastery is what compounds *after* you're getting
paid. At 1 hour/day, 3 months makes you dangerous, not a master — and that's exactly enough to
earn your first money.

## Phase 0 — Week 1: Setup + fundamentals

**Setup**
- Install **Git**
- Create a GitHub account
- Use **VS Code** (already installed)
- Learn `venv` and how to run a file

**Learn**
variables · types · f-strings · if/else · loops · functions · lists · dicts · files · errors

**Project:** `portfolio-app` **stage 1** — a JSON-driven terminal portfolio: intro, links, skills,
projects, achievements. The code exists; your job is to make the content real.

**Done when:** 1 repo on GitHub, 10+ commits, `python main.py` prints your actual portfolio.

## Phase 1 — Weeks 2–4: Automation (your first sellable skill)

**Learn**
modules · `pip` · `pathlib` · `json` · `csv` · `requests` · APIs · `BeautifulSoup` · error handling

**Build four tools**
1. **File organizer** — sorts Downloads into folders by extension
2. **Bulk renamer** — renames files with a pattern and numbering
3. **API tool** — weather or Minecraft server status, printed to the terminal
4. **CSV/Excel report** — reads a spreadsheet, produces a summary

**Done when:** 3 finished scripts in one repo, each with a README and a screenshot.

## Phase 2 — Weeks 5–8: Portfolio app, GUI → web

**Learn**
Tkinter · widgets and layout · event handlers · SQLite · Flask · HTML/CSS · deployment · environment
variables

**Build**
1. **Stage 2 — Tkinter desktop app** — sidebar of sections, scrollable content, reads the same JSON

**Done when:** a public link to the web portfolio, a working desktop app, and a screenshot or GIF in
the README.

## Phase 3 — Weeks 9–12: Get paid

**Services and starting prices**

| Service | Price |
|---------|-------|
| Small portfolio / landing site | $50–200 |
| Custom small Python tool (desktop or web) | $50–200 |
| Automation script | $30–150 |

**Where**
r/forhire · Upwork · Fiverr · local businesses · creator and gaming communities · people
complaining about repetitive manual work in forums and Discord servers

**How**
- 10 outreach messages a day (same discipline as the video plan)
- First 2 clients at a low price for a testimonial

## The 5 non-negotiables

1. **Code every day.** Even 20 minutes.
2. **Commit to GitHub every day.** Green squares are proof.
3. **Build > watch.** If you watched more than you built, the day doesn't count.
4. **Finish projects.** One finished beats five abandoned.
5. **Charge from the first client.** Small is fine. Free is not.

## Honest limits

- 1 hour/day for 12 weeks ≈ 84 hours. That's enough to build small paid tools — not to be a
  senior developer.
- Your first money may take **2–4 months**, and it won't be much. That's normal.
- Your laptop is **fine for Python.** The bottleneck is consistency, not hardware.
- "Mastery" is a 5–10 year direction, not a prerequisite. Start earning at competent.
